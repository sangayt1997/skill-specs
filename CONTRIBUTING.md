# Contributing

Contributions to `skill-specs` are welcome.

- Add new skills to the most appropriate category using a lowercase, kebab-case directory whose name matches the skill's YAML `name`.
- Update existing skills with focused, actionable guidance and preserve established scope.
- Keep guidance technology-independent unless the skill intentionally targets a framework or vendor.
- Check existing skills before adding one to avoid duplicate or overlapping responsibilities.
- Keep instructions concise, consistent, and practical for AI coding agents.
- Submit changes through a pull request with a clear explanation of the scope and rationale.

The detailed contribution rules will evolve with the repository.
