# Security Policy

## Supported Versions

This repository publishes documentation and AI-agent skill specifications rather than executable application releases. Security corrections are applied to the latest content on the default branch.

## Reporting a Vulnerability

Do not report a suspected vulnerability, exposed secret, unsafe agent instruction, or supply-chain concern in a public issue.

Use GitHub's **Security** tab and select **Report a vulnerability** to submit a private report. Include:

- the affected file or workflow;
- the potential impact;
- steps or an example that demonstrates the issue; and
- any suggested mitigation.

The maintainer will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure and remediation. If private vulnerability reporting is unavailable, contact [@sangayt1997](https://github.com/sangayt1997) through the contact information published on the maintainer's GitHub profile.

Reports about ordinary correctness, clarity, or documentation problems should use the public issue forms instead.
