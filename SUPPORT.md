# Support

Use the appropriate channel so requests can be handled efficiently:

- **Questions and design discussion:** use GitHub Discussions.
- **New skill proposals or improvements:** use the structured issue forms.
- **Documentation defects:** use the documentation issue form.
- **Security concerns:** follow [SECURITY.md](SECURITY.md) and report privately.
- **Conduct concerns:** follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Issues are intended for actionable repository work, not general support conversations. Support is community-maintained and does not have a guaranteed response time.
