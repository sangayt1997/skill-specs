# Creating a Skill

Use this introductory workflow:

1. Choose the correct category.
2. Create a lowercase, kebab-case directory.
3. Add a `SKILL.md` entry file.
4. Add valid YAML frontmatter.
5. Define clear scope and activation conditions.
6. Follow the repository authoring standards.
7. Check for overlap with existing skills.

The complete authoring system will be documented as the standards evolve.
